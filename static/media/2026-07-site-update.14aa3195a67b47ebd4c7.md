I've had this site for a while, and frankly have not been particularly diligent about keeping it up to date. Recently, I decided that I wanted to update this site--change up the whole theme, add some more features, etc. etc. Specifically, I settled on three loose goals:

1. Simplify and modernize the UI.
2. Add a blogging feature for writing pieces like this!
3. Comprehensively update all information on the site.
4. Bonus: Accommodate for viewing on mobile UI.

I was doing some research on personal sites and stumbled upon this one from [SJ Zhang](https://www.sj.land/). I really love the clean UI and the addition of the sidebar, which allowed for more flexibility in adding subcategories to my site compared to a typical top-aligned NavBar.

This new version of my site is heavily inspired by this design. However, I did add some personal touches. Below are the

- **Single, Fully Scrollable Page with Anchors**: This is similar to my original site. I liked the feature of being able to access all information without any clicking--i.e., each of the main sections on the sidebar are not separate pages, but rather just anchors on the same page. For someone who is just stopping by the site, it allows for a quick skim without the hassle of deciding which links to click into.
- **Cohesive, Modular Visual Identity**: I love the "summary" modules used on the home page of the original site. However, for my site I hope to create a more cohesive visual identity by using the same base component across modules for the different sections. Each module will be accompanied by an image, title, and description.
- **Personalized Sections**: Obviously, I opted to tailor the sections to my own needs. Eventually, I settled on 5 main sections: Home, About, Projects, Contact, Blog. These are the main sections that will be featured

- this was my first time trying to fully handle window resizing and accommodating for the UI. specifically, i spent a lot of time on the home page components trying to get the resizing intuitive and clean.
